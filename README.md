Site oficial de divulgação da 9ª Festa da Pizza da ETEC de Fernandópolis, desenvolvido para apresentar o evento e facilitar o acesso da comunidade às informações.

## Site publicado

[Visitar a página da Festa da Pizza](https://pizzaetec-accf1.web.app/)

## Destaques

- página responsiva para divulgação do evento;
- conteúdo centralizado em uma experiência simples;
- hospedagem no Firebase Hosting;
- deploy automático com GitHub Actions;
- configuração do Firebase versionada no repositório.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Firebase Hosting
- GitHub Actions

## Execução local

~~~bash
git clone https://github.com/ArthurFancisco/PizzaEtec.git
cd PizzaEtec
python -m http.server 5500
~~~

Acesse http://localhost:5500.

## Deploy

O repositório contém um workflow responsável pelo deploy no Firebase Hosting. Segredos de autenticação devem permanecer apenas nas configurações protegidas do GitHub Actions.
